Can Mathematics Help Us Distinguish Iris Flower Species?

Advanced Mathematics Project | Data Analysis with Python

1. Research Question

How can mathematical relationships between flower measurements help distinguish different iris species?

This project explores differences in petal measurements and the linear relationship between petal length and petal width.

2. Dataset

The Iris dataset contains 150 flowers from three species: Iris-setosa, Iris-versicolor, and Iris-virginica. Each flower has four numerical measurements in centimetres.

4. Analysis Two: Linear Regression

Ordinary least squares (OLS) estimates the relationship between petal length (x) and petal width (y).

Estimated equation:

Predicted petal width = 0.4164 × petal length − 0.3665

R² = 0.9269

Approximately 92.69% of the variation in petal width is explained by petal length in this pooled linear model. The positive slope indicates that flowers with longer petals tend to have wider petals.

Because the model combines all three species, the strong relationship does not by itself establish how accurately individual flowers can be classified.

View Figure 2 (PDF)

5. Conclusion

The analyses show clear differences in average petal length among iris species and a strong overall linear association between petal length and width.

These mathematical patterns can help us understand species differences, although further classification analysis would be required to measure identification accuracy for individual flowers.
